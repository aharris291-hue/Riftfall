# Riftfall: The Last Ascent

A cinematic horror-survival adventure for Roblox. This repository holds the
**first playable demo**: a short vertical slice of *Chapter 1: The Forgotten
Expedition*, about 10 to 15 minutes long.

> You survive a helicopter crash in a stormy jungle, follow a twelve-year-old
> distress signal past an abandoned expedition camp, sneak through ruins
> patrolled by a creature that hunts by sound, solve the temple door, and
> escape the collapse to a rescue flare.

The design bible is the **Riftfall Master Prompt** PDF. See
[`docs/DESIGN.md`](docs/DESIGN.md) for how this demo maps onto it.

## Play it in Roblox Studio (no coding or extra tools needed)

1. **Install Roblox Studio** if you don't have it: <https://create.roblox.com>
   then "Start Creating". Sign in with your Roblox account.
2. **Download the place file** `Riftfall.rbxlx` from this repository
   (on GitHub, open the file and click the download button, "Download raw file").
3. **Open it**: double-click `Riftfall.rbxlx`, or in Studio choose
   *File > Open from File...* and pick it.
4. **Open the Output window** so you can see messages and errors:
   *View* tab > *Output*.
5. **Press Play** (the big ▶ button on the *Home* tab, or press **F5**).

> **Note:** the editor view looks empty before you press Play. That is
> expected: the whole world is built by code the moment the game starts
> (see "Why is the world built by code?" below).

When the game starts you should see `[Riftfall] Server ready.` and
`[Riftfall] Client ready.` in the Output window, and you'll be standing next
to a burning helicopter in the rain.

To stop, press the red ■ *Stop* button (or **Shift+F5**).

### Controls

| Action | Keyboard / mouse | Touch (phone/tablet) |
|---|---|---|
| Move | W A S D | Left thumbstick |
| Look | Right mouse drag | Drag on screen |
| Sprint (loud!) | Hold **Left Shift** | Hold **Sprint** button |
| Crouch (quiet) | Press **C** (toggles) | **Crouch** button |
| Flashlight | **F** | **Light** button |
| Interact (pick up, read, turn) | Hold/press **E** at the prompt | Tap the prompt |
| Use inventory item | **1-4**, or click the slot | Tap the slot |
| Drop item | Click the small **X** on the slot | Tap the **X** |
| Brightness (too dark?) | Click **Brightness** under the objective | Tap **Brightness** |
| Change Jax's outfit | Click **Outfit** under the objective | Tap **Outfit** |
| Talk to Serra, Kade, Lira | Press **E** at the Talk prompt | Tap the prompt |
| Skip subtitle / close note | **Enter**, or click it | Tap it |

### How to survive

- **The Rift Stalker hunts by sound and sight.** Sprinting is loud, walking is
  quiet, crouching is almost silent. Your flashlight lets it see you from
  further away.
- **Hide in tall grass**: crouch inside a grass patch and it can't see you
  unless it is right next to you.
- **Break line of sight** behind pillars and walls. It searches where it last
  saw you, then gives up and goes back to patrolling.
- When it winds up an attack its **eyes flare red**. Move away and the hit
  misses.
- The screen edges **pulse purple** as it gets close and flash **red** when
  you're hurt.
- **Bandages** heal 35. **Batteries** recharge your flashlight. Health does
  not regenerate on its own.
- **Read the notes.** One of them tells you how to open the temple door.
- **Green flares are checkpoints.** If you die you come back at the last one
  you touched, and you keep your items.

## Why is the world built by code?

The map is generated by `src/server/Services/LevelBuilder.luau` when the
server starts. That keeps the entire game as plain text (easy to review, easy
to rebuild), and "Play Again" can reset the world simply by rebuilding it.
The trade-off is that you don't see the map while editing in Studio. A later
milestone can switch to hand-built maps once the layout is final.

## For developers: working with Rojo

The source of truth is the `src/` folder. `Riftfall.rbxlx` is **generated**
from it with [Rojo](https://rojo.space) 7.x:

```bash
rojo build default.project.json -o Riftfall.rbxlx
```

To live-sync while editing in Studio instead:

1. Install the Rojo Studio plugin (Studio > Toolbox > Plugins, search "Rojo",
   or from <https://rojo.space/docs>).
2. Run `rojo serve` in this folder.
3. In Studio, open the Rojo plugin and click **Connect**.

Smoke tests (optional, needs [Lune](https://lune-org.github.io/docs) 0.11+).
They run the map builder, the HUD, the creature model and the inventory rules
against Lune's Roblox instance model, which rejects wrong property names and
types. They do **not** simulate physics, AI movement, or networking:

```bash
lune run tools/smoke/levelbuilder_smoke.luau . /tmp/level.rbxlx
lune run tools/smoke/runtime_smoke.luau .
```

Lint and format (optional):

```bash
stylua src/        # formatting (config: stylua.toml)
selene src/        # linting (run `selene generate-roblox-std` once first)
```

## Troubleshooting

| Problem | What to try |
|---|---|
| Nothing happens / I fall forever when I press Play | Open *View > Output* and look for red text. Copy the red lines and send them over. |
| "Rojo" errors | You don't need Rojo just to play: open `Riftfall.rbxlx` directly. |
| It's too dark to see | Press **F** for the flashlight, or click **Brightness** under the objective panel. To change it for everyone, raise the values in `Config.Lighting` (`src/shared/Config.luau`). |
| The creature never moves | Check Output for `[StalkerService] AI tick failed` and send that error text. In the Explorer, `Workspace > RiftStalker` shows a `State` attribute (Patrol, Chase...) that helps diagnose it. |
| No sound | Expected for now: no audio has been chosen yet. See "Assets and placeholders" in `docs/STATUS.md`. |

**Sharing an error:** in the Output window, right-click > *Copy*, or select
the red lines and press Ctrl+C, then paste them into the project chat
together with what you were doing at the time.
